# 음식 이상형 월드컵 128강

정적 HTML/CSS/JS로 만든 MVP입니다.

## 실행
`index.html`을 브라우저에서 열면 됩니다. 로컬 서버를 권장합니다.

## 배포
- Cloudflare Pages: 이 폴더 자체를 직접 업로드
- Vercel: 이 폴더를 프로젝트 루트로 배포
- 별도 빌드 명령 없음
- 출력 디렉터리 없음

## 데이터
- `data.js`: 128개 음식 DB 및 균형 128강 대진
- 128강: 사전 설계된 균형 대진
- 이후 라운드: 승자끼리 순차 대결

## 기능
- 128강부터 결승까지 전체 진행
- 진행 상태 localStorage 저장
- 이어하기 / 초기화
- 이전 선택 1단계 이상 복원 가능
- 키보드 좌/우 선택
- 최종 결과 복사

## 이미지
MVP에서는 외부 이미지 저작권/로딩 문제를 피하기 위해 음식별 이모지를 사용했습니다.
정식 버전에서는 `food_id` 기준 WebP 이미지를 연결하는 것을 권장합니다.
